# 🎓 Исторический портал «Chronos»

### Описание
Интерактивный многостраничный сайт-архив, посвященный великим историческим эпохам человечества. Проект разработан с использованием семантической разметки HTML5, адаптивных стилей CSS3 и интерактивных элементов на чистом JavaScript.

### 🚀 Функциональность
* 📱 **Адаптивный дизайн:** Корректное отображение на смартфонах, планшетах и десктопах благодаря медиа-запросам.
* 📜 **Стабильные CSS Анимации:** Плавное появление страниц при загрузке.
* 💾 **Сохранение данных:** Интеграция формы обратной связи с хранилищем `localStorage`.
* 🧭 **Удобная навигация:** Единые Header и Footer для быстрой миграции между страницами.

### 📁 Структура проекта
* `index.html` — Главная страница с Hero-блоком и статистикой.
* `about.html` — История разработки, цели и задачи коллегии летописцев.
* `blog.html` — Архив статей по ключевым эпохам (Рим, Русь).
* `gallery.html` — Выставка реликвий (галерея картинок).
* `contact.html` — Форма отправки писем в Скрипторий.
* `css/style.css` — Файл оформления, анимаций и адаптивных сеток.
* `js/script.js` — Логика работы с формами.
